# ADR 0004 — The model compiles, audits, composes and explains. It does not decide

Date: 2026-09-02
Status: **Accepted** (Phase 4 shipped on it; recorded 2026-09-03 in T5.7)

## Context

This is a submission to an **AI** buildathon track, and the obvious shape for one is an
agent that reads the book and says who to contact. That shape was available: the mandate
features, the hazard scores and the channel costs all fit comfortably in a prompt, and a
model asked to rank them would return something plausible.

Two requirements make it unusable here.

**The headline number must replay.** [`results.md`](../results.md) §2 is regenerated by CI
and byte-diffed against the committed copy ([ADR 0003](./0003-determinism-of-derived-data.md)),
and `mandateguard replay --decision-id X` re-runs any single historical decision from
`(policy_hash, model_version, seed, snapshot)`. A ranking produced by a hosted model
satisfies neither. Temperature 0 is not a reproducibility guarantee: the model version, the
serving stack and the account are all outside this repository, and a decision that cannot
be re-run cannot be audited by the person it was made about.

**A refusal must name a clause.** [`calibration.md`](../calibration.md) §1 pins twenty
compiled rules to a specific RBI circular with a verbatim quote each. "The model judged this
non-compliant" is not a finding a payments team can act on; "clause 6(a), and here is the
sentence" is.

## Decision

**`agent/` is the only package that touches an LLM, and none of its four jobs returns an
allocation.**

| job | what the model does | what runs without it |
|---|---|---|
| Policy compiler (T4.1) | reads the circular text once, proposes rules | `scripts/compile_policy.py --check` re-verifies all twenty against the source with no model at all |
| Mandate auditor (T4.2) | optional second opinion | `RulesAuditor` — deterministic, clause-named |
| Notice composer (T4.3) | drafts wording | `TemplateComposer`, plus a plain-Python compliance linter (T4.4) that both must pass |
| Refusal explainer (T4.5) | plain-language reason | a template with the rupee terms filled in |

Every one of the four runs to completion with `client=None`. The deterministic path is the
**ordinary** path, not an emergency one — which is why `RULES_ONLY` in the degradation
ladder ([ADR 0005](./0005-shadow-mode-and-the-degradation-ladder.md)) *records* a state
rather than creating a behaviour.

Selection stays in `allocator/`: a multiple-choice knapsack over rupee terms computed in
`value/`, under a budget, with the LP dual as theta.

## Consequences

**What this costs.** A genuinely better ranker is left unbuilt, and the demo is less
striking than an agent that "reads the book and decides". If a model would have selected
better than the knapsack, this project does not know it and has not measured it.

**What it buys.** Every decision in the ledger replays byte-identically. Every compliance
verdict cites a clause and a quote. The chaos suite can kill the model and the system still
answers, because answering never depended on it.

**Where it is weakest.** `docs/llm_eval.md` scores the rules arm 114/114 on the golden set,
which is a weaker result than it looks: the same reader wrote the cases and the rules
(`limitations.md` §8.7), and the adversarial gap is +0.0 on a set this project wrote to
break itself (§8.8). A 100% that nobody independent produced is a statement about the test.

**What enforces it.** `agent/` imports nothing from `allocator/`. `tests/test_chaos.py`
removes the client and asserts each of the four jobs still returns.

## Alternatives rejected

**Model ranks, rules veto.** The model proposes an ordering and the compiled rules filter
it. Rejected because the *ordering* is where the money is: a veto layer makes illegal asks
impossible without making the expensive ones reproducible, and the headline number would
still not replay.

**Model decides, log the prompt.** Rejected on the same ground. A logged prompt reproduces
the input, not the output.
